# Anchor Tag Examples

This project demonstrates the use of anchor (`<a>`) tags in HTML to create hyperlinks.

## Example Code

The following HTML snippet creates a simple hyperlink to an external website:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Anchor Example</title>
    <meta charset="utf-8" />
  </head>
  <body>
    <a href="http://webdevbasics.net"
      >Basics of Web Design Textbook Companion</a
    >
  </body>
</html>
```
