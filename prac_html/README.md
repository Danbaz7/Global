# Anchor Tag Example

This project demonstrates the use of anchor (`<a>`) tags in HTML to create hyperlinks.

## Example Code

The following HTML snippet creates a simple hyperlink to an external website:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Anchor Example</title>
    <meta charset="utf-8" />
  </head>
  <body>
    <a href="http://webdevbasics.net"
      >Basics of Web Design Textbook Companion</a
    >
  </body>
</html>
```

# Block-Level Anchor Example

This project demonstrates how anchor (`<a>`) tags can wrap block-level elements in HTML.

## Example Code

The following HTML snippet showcases a block-level anchor tag:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>Block Anchor</title>
    <meta charset="utf-8" />
  </head>
  <body>
    <header>
      <a href="http://www.w3.org/TR/html-markup">
        <h1>HTML5 Reference</h1>
        <p>Bookmark this site for a handy HTML5 reference.</p>
      </a>
    </header>
    <main>
      <p>Website content goes here</p>
    </main>
  </body>
</html>
```
