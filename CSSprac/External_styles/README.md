# Forms HTML & CSS

This folder demonstrates the creation of accessible, responsive, and visually appealing web forms using semantic HTML5 and modern CSS3. The project showcases best practices in structuring forms, applying advanced styling, and ensuring usability across all devices and print formats.

## Features

### Semantic HTML Structure

- Uses appropriate HTML5 elements such as `<form>`, `<label>`, `<input>`, `<select>`, and `<button>` for clarity, accessibility, and maintainability.
- All form fields are properly labeled, with required fields clearly indicated for better user experience and accessibility.

### Responsive Design

- **Media Queries:**  
  CSS media queries adapt the form layout, font sizes, and spacing for optimal usability on mobile, tablet, and desktop screens.
- **Flexbox & Grid:**  
  CSS Flexbox and Grid are used to align and organize form elements, ensuring a clean and flexible layout that adjusts smoothly to different screen sizes.

### Visual Styling

- **Consistent Theme:**  
  The form and navigation are styled with a cohesive color palette, padding, and spacing for a professional look.
- **Focus & Validation:**  
  Visual cues for required fields and focus states improve usability and accessibility.
- **Navigation:**  
  The navigation bar is styled to be responsive and accessible, adapting its layout for smaller screens.

### Print Styles

- **Print CSS:**  
  A dedicated print stylesheet (`contactprint.css`) ensures the form prints cleanly, removing unnecessary images, backgrounds, and large font sizes for a paper-friendly layout.

### Accessibility

- **Clear Labels:**  
  All inputs are associated with labels for screen reader compatibility.
- **Keyboard Navigation:**  
  The form is fully navigable via keyboard, with visible focus states.
