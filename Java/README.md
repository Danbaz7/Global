# Java Projects Overview

This repository contains a series of Java programming assignments by Daniel Obazee. The `proj1` to `proj13` folders contain standalone introductory Java programs focused on specific concepts or problems. The `DSA` folder contains newer data structures and algorithms coursework for CSCI 251.

## Folder Summaries

- **proj1**: Calculates and displays the projected population for the next five years based on birth, death, and immigration rates.
- **proj2**: Takes an amount in cents and computes the minimum number of quarters, dimes, nickels, and pennies needed. Also generates a random cent value and performs the same breakdown.
- **proj3**: Evaluates a user's integer score (0–100) and assigns a letter grade (A–F) using both if-else and switch logic. Includes a bonus feature to compute the square root of a number.
- **proj4**: Converts a binary string input to its decimal equivalent using both Java's built-in method and a manual calculation. Validates input for binary correctness.
- **proj5**: Implements a mortgage calculator that prints an amortization table, tracks total interest paid, and allows repeated calculations using loops.
- **proj6**: Processes strings to count all English letters and the occurrences of a specific letter (case-insensitive). Allows repeated tests and validates input.
- **proj7**: Demonstrates array operations: initializes an array with random integers, allows searching, sorting, and analysis (range, average, min, max) via a menu-driven interface.
- **proj8**: Converts a number (0–511) to a 3x3 matrix of coins (heads/tails) by interpreting the number as a 9-bit binary string and mapping bits to coin sides.
- **proj9**: Models a `Temperature` class with multiple constructors, conversion methods, and comparison logic. The main program demonstrates object-oriented principles and user interaction.
- **proj10**: Implements a custom string class (`danielObazeeMyStringProj10`) that mimics Java's String functionality (charAt, length, substring, toLowerCase, equals, valueOf) without using built-in String classes.
- **proj11**: Demonstrates inheritance and polymorphism with a bank account hierarchy (`Account`, `CheckingAccount`, `SavingsAccount`). Performs deposits, withdrawals, and interest calculations, printing account details.
- **proj12**: Extends the bank account hierarchy with custom exception handling for illegal transaction amounts and insufficient funds, demonstrating robust error management.
- **proj13**: Prints a formatted calendar for a specified month and year, using Java's Calendar classes to determine dates and layout.

## Data Structures and Algorithms

The `DSA` folder includes CSCI 251 projects focused on algorithm analysis and custom data structure implementations:

- **DSA/projOne**: Compares linear search and binary search on randomly generated integer arrays.
- **DSA/projTwo**: Implements and benchmarks insertion sort, selection sort, quick sort, and merge sort.
- **DSA/projThree**: Adds an ArrayList-backed generic stack implementation and sorting test code.
- **DSA/projFour**: Implements a generic hash table with separate chaining through custom hash entries.
- **DSA/projFive**: Implements a generic binary search tree with insert, search, remove, height, size, and traversal behavior.
- **DSA/projSix**: Implements a weighted directed graph using an adjacency matrix, with breadth-first search (BFS) and depth-first search (DFS) traversal.
