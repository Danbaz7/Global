# DanielObazeeProj8

## 📖 Overview

This Java program is a **coin matrix converter** that takes a number between **0 and 511** and converts it into a **3x3 matrix of coins**.  
It demonstrates binary conversion, input validation, and the use of the **ternary operator** for character mapping.

## ⚙️ Features

- Prompts the user for an integer between `0` and `511`.
- Validates input to ensure it falls within the correct range.
- Converts the number into a **9-bit binary string**.
- Maps each binary digit to a coin state:
  - `0 → H` (Heads)
  - `1 → T` (Tails)
- Displays the result as a **3x3 matrix** of coins.
