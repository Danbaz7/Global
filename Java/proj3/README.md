# DanielObazeeProject03

## 📖 Overview

This Java program evaluates a grade based on an integer score between **0 and 100**.  
It demonstrates two approaches for grade evaluation:

- Traditional `if-else` statements
- Modern `switch` expression (Java 14+ style)

Additionally, the program includes a **bonus feature** that calculates the square root of a user-provided number using `Math.pow()`.

## ⚙️ Features

- Validates user input to ensure scores are between 0 and 100.
- Maps scores to letter grades:
  - **A**: 90–100
  - **B**: 80–89
  - **C**: 70–79
  - **D**: 60–69
  - **Fail**: below 60
- Provides two grading implementations (`if-else` and `switch`).
- Bonus practice: calculates square root of a number using `Math.pow()`.
