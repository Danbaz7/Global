# DanielObazee_Proj01

## 📖 Overview

This project is a simple Java program that estimates the population growth of the United States over a five‑year period based on fixed birth, death, and immigration rates.

## ⚙️ How It Works

- **Initial population**: `312,032,486`
- **Seconds per year**: `365 * 24 * 3600`
- **Rates**:
  - Birth: one every 7 seconds
  - Death: one every 13 seconds
  - Immigration: one every 45 seconds
- **Computation**:
  - Calculates the net population change per year using the above rates.
  - Adds the computed change to the current population for each year (1–5).
- **Output**:
  - Prints the projected population after 1, 2, 3, 4, and 5 years.
