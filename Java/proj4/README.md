# DanielObazeeProject04

## 📖 Overview

This Java program converts a binary string (composed of `0`s and `1`s) into its corresponding decimal value.  
It demonstrates two approaches:

1. **Built-in conversion** using `Integer.parseInt(binary, 2)`
2. **Manual conversion** by iterating through each binary digit and applying positional weights with `Math.pow()`

The program also includes input validation to ensure only valid binary strings are processed, showcasing both practical use of Java libraries and a foundational understanding of binary number systems.

## ⚙️ Features

- Accepts user input as a binary string.
- Validates input to allow only `0` and `1` characters.
- Converts binary to decimal using:
  - Java’s built-in `Integer.parseInt()`
  - Manual calculation with positional weights
- Displays both conversion results for comparison.
