# DanielObazeeProj05

## 📖 Overview

This Java program is a **mortgage calculator** that generates an amortization table and tracks the **total interest paid** over the life of a loan.  
It demonstrates both practical financial calculations and programming concepts such as loops and input validation.

## ⚙️ Features

- Prompts the user for:
  - Loan principal
  - Annual interest rate (decimal format, e.g., `0.05` for 5%)
  - Loan term in years
- Calculates:
  - Monthly interest rate
  - Monthly payment using the amortization formula
- Prints a detailed amortization schedule showing:
  - Month number
  - Payment amount
  - Interest portion
  - Cumulative interest
  - Principal portion
  - Remaining balance
- Tracks and displays the **total interest paid**.
- Allows the user to **retry calculations** using a `do-while` loop.
- Includes an **extra credit** implementation with a `while-loop` version (commented out).
