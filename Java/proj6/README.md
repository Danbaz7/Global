# DanielObazeeProject06

## 📖 Overview

This Java program reinforces **string-processing concepts** by working with user input.  
It provides two methods for analyzing text:

1. Count all English letters in a given string.
2. Count occurrences of a specific English letter (case-insensitive).

The program also validates input, returns `-1` if the specified character is not an English letter, and allows the user to repeat tests via a `do-while` loop.

## ⚙️ Features

- Prompts the user to enter a string.
- Counts the total number of English letters in the string.
- Prompts the user to enter a character:
  - Counts occurrences of that character (case-insensitive).
  - Returns `-1` if the character is not a valid English letter.
- Allows repeated testing until the user chooses to exit.
