# DanielObazeeProjectSeven

## 📖 Overview

This Java program reinforces **single-dimensional array concepts** by providing a menu-driven interface for array operations.  
It demonstrates initialization, searching, sorting, and statistical analysis of array data.

## ⚙️ Features

- Initializes an array with **25 random integers** between 1 and 100.
- Provides a **menu-driven interface** with options to:
  1. Initialize array with random values
  2. Print array (5 elements per line)
  3. Perform linear search
  4. Sort array using selection sort
  5. Calculate range (max – min)
  6. Find largest element
  7. Find smallest element
  8. Compute average of elements
  9. Re-run or exit program
- Implements **linear search** and **selection sort** algorithms.
- Calculates **range, average, largest, and smallest values** in the array.
- Allows repeated execution until the user chooses to exit.
