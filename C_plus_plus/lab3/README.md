# Lab 3: Grade to Letter Converter

This C++ program allows users to enter a numeric grade (0-100) and prints the corresponding letter grade (A, B, C, D, or F) to the console. The program validates user input and allows repeated entries until the user chooses to exit.

## How It Works

- The user is prompted to enter a grade between 0 and 100.
- The program checks for valid numeric input and ensures the grade is within the valid range.
- Based on the entered grade, the program outputs the corresponding letter grade:
  - 90–100: A
  - 80–89: B
  - 70–79: C
  - 60–69: D
  - Below 60: F
- After each entry, the user is asked if they want to enter another grade.
- The program continues until the user enters 'n' or 'N', then displays a thank you message.
