# Project 9: String and Array Manipulation Functions

This C++ program demonstrates various string and dynamic array manipulation functions, including reversing C-strings, encoding/decoding strings, searching for entries, adding and deleting entries in dynamic arrays, and printing array contents.

## Features

- **Reverse C-string:** Reverses the characters in a C-string in place.
- **Encode/Decode C-strings:**
  - Switches even-numbered letters between two C-strings of equal length.
  - Encodes a C-string by adding a specified value to each character's ASCII code.
  - Decodes by reversing the encoding process.
- **Find Entry:** Searches for a string in an array and returns its index.
- **Add Entry:** Adds a new string to a dynamic array, resizing the array.
- **Delete Entry:** Removes a specified string from a dynamic array, resizing the array.
- **Print Array:** Prints each element of a string array with its index.

## How It Works

- The program tests each function with sample data in `main()`.
- Demonstrates reversing strings, encoding/decoding, searching, adding, deleting, and printing array elements.
- Uses dynamic memory allocation for array operations.
