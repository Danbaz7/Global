# Lab 1: Coin Value Calculator

This program, written in C++, calculates the total value of a collection of U.S. coins (quarters, dimes, and nickels) entered by the user. It outputs the total value in both cents and dollars.

## How It Works

- The user is prompted to enter the number of quarters, dimes, and nickels (all must be non-negative integers).
- The program multiplies each coin count by its value in cents (quarters = 25, dimes = 10, nickels = 5).
- It sums the values to get the total in cents, then converts and displays the result in dollars.
