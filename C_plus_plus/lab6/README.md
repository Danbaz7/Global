# Lab 6: File Word Counter

This C++ program counts the number of words in a user-specified input file and appends the result to an output file, as well as displaying it on the console. It demonstrates file input/output operations, user interaction, and basic word counting.

## How It Works

- The program welcomes the user and explains its purpose.
- The user is prompted to enter the names of the input and output files (including file extensions).
- The program attempts to open both files. If either fails, an error message is displayed.
- It reads the input file, counts the number of words, and stores the result.
- The word count is printed to the console and appended to the output file.
- Both files are closed before the program exits.
