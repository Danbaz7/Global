# Lab 7: Student Scores and Grade Table

This C++ program allows the user to input scores for a set of students, then displays a formatted table showing each student's number, score, and corresponding letter grade.

## How It Works

- The user is prompted to enter the scores for 5 students.
- The program stores the scores in an array.
- For each score, the program determines the letter grade using the following scale:
  - 90 and above: A
  - 80–89: B
  - 70–79: C
  - 60–69: D
  - Below 60: F
- The results are displayed in a neatly formatted table.

## Example Output

```
Enter score for student 1: 85
Enter score for student 2: 92
Enter score for student 3: 78
Enter score for student 4: 88
Enter score for student 5: 60

+---------+-------+-------+
| Student | Score | Grade |
+---------+-------+-------+
|    1    |  85   |   B   |
|    2    |  92   |   A   |
|    3    |  78   |   C   |
|    4    |  88   |   B   |
|    5    |  60   |   D   |
+---------+-------+-------+
```
