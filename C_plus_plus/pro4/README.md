# Project 4: Prime Number Checker

This C++ program checks whether a given integer is a prime number. The user is prompted to enter an integer, and the program determines if the number is prime or not, displaying the result.

## How It Works

- The user is prompted to enter an integer.
- The program checks if the number is less than 2 (not prime).
- For numbers 2 and above, the program checks divisibility from 2 up to the square root of the number.
- If the number is divisible by any of these, it is not prime; otherwise, it is prime.
- The result is displayed to the user.
