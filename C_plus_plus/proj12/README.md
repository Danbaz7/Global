# 🧮 Fraction Class Tester

This C++ program, authored by Daniel Obazee for Project 2, demonstrates a fully featured `Fraction` class and its related operations, along with an automated test suite to validate correctness and style.

## 📘 Description

The goal of this project is to:

- Design a robust class that models mathematical fractions.
- Overload operators for arithmetic and comparison.
- Implement input/output formatting.
- Write unit-style tests to validate class functionality.

## 🧩 Key Features

### ✅ Fraction Class Highlights:

- Constructors for default, whole number, and fractional inputs.
- Automatic handling of negative denominators.
- Simplification using the Euclidean algorithm.
- Reciprocal, negation, and reduction logic.
- Overloaded operators: `+`, `-`, `*`, `/`, `<`, `>`, `<=`, `>=`, `==`, `!=`.
- Stream I/O support (`>>`, `<<`).
