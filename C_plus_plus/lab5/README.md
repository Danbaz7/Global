# Rectangle Area Calculator

This C++ program, authored by Daniel Obazee for CSCI 121 Lab 5, calculates the area of a rectangle based on user-provided dimensions.

## 📌 Purpose

The program demonstrates the use of:

- Function prototypes and definitions
- Input/output operations
- Pass-by-reference parameters
- Basic arithmetic operations

## 🧠 How It Works

1. Prompts the user to enter the length and width of a rectangle.
2. Uses separate functions to collect the input:
   - `getLength()`
   - `getWidth()`
3. Passes these dimensions to `calculateArea()` using reference parameters.
4. Displays the calculated area.
