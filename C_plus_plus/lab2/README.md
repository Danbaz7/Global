# Lab 2: Number Sign Checker

This C++ program allows the user to repeatedly enter integers and determines whether each number is positive or non-positive. The user can continue entering numbers or exit the program based on their input.

## How It Works

- The program prompts the user to enter an integer.
- It checks if the input is a valid integer. If not, it asks the user to try again.
- After a valid number is entered, the program displays whether the number is positive or non-positive.
- The user is then asked if they want to enter another number (`y` for yes, `n` for no).
- If the user enters `n` or `N`, the program prints "Good Bye!" and exits.
- If the user enters an invalid choice, the program notifies them with "Invalid input."
