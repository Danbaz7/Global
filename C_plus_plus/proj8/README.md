# Project 8: Score Statistics and Palindrome Checker

This C++ program provides two main functionalities:

1. Collects integer scores from the user, computes and displays statistics (maximum, minimum, total count, and average).
2. Checks whether a user-entered sentence is a palindrome, ignoring spaces, punctuation, and case.

## How It Works

### Score Statistics

- The user is prompted to enter scores between 0 and 100.
- Input ends when the user enters -1.
- The program calculates and displays:
  - Total number of scores
  - Highest score
  - Lowest score
  - Average score (to 4 decimal places)
- The user can repeat the process for another set of scores.

### Palindrome Checker

- The user enters a sentence.
- The program checks if the sentence is a palindrome, ignoring non-alphanumeric characters and case.
- Displays whether the sentence is a palindrome.
- The user can check additional sentences.
