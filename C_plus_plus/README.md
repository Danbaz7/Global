# 📚 C_plus_plus Folder Overview

This folder contains a comprehensive collection of C++ lab assignments and projects for the CSSI 121 course, authored by Daniel Obazee. Each subfolder focuses on a specific programming concept or real-world application, ranging from basic input/output and control structures to advanced topics like file handling, dynamic arrays, string manipulation, and algorithmic problem solving.

## 🗂️ Contents

- **Labs:**  
  Step-by-step exercises designed to reinforce foundational C++ skills, such as arithmetic operations, conditionals, loops, functions, arrays, and file I/O.

- **Projects:**  
  Larger, application-oriented programs that integrate multiple concepts. These include calculators, games, data processing utilities, and algorithm challenges.

## 📝 How to Use

1. **Browse the folders:** Each lab and project is in its own directory (e.g., `lab1`, `proj9`).
2. **Read the README.md:** Every folder contains a README with a description, usage instructions...
